# Before you merge agent work

- [ ] I ran `./verify.sh` myself, or saw its real output
- [ ] The diff touches only what the feature needs
- [ ] `feature_list.json` changed only in `passes` and `notes`
- [ ] No tests were deleted, skipped or weakened
- [ ] No secrets, credentials or real data were added to the repo
- [ ] `progress.md` says what was done and what is left
- [ ] A person reviewed the change, as for any other pull request
