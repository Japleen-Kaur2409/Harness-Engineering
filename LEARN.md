# Learn more

You do not need any of this to use the templates. Read it when you want to know why they work.

## 10 minutes

- [Learn Harness Engineering](https://github.com/walkinglabs/learn-harness-engineering): open-source course; the README alone explains the five parts of a harness (instructions, state, verification, scope, session lifecycle).
- [Agent Harness Engineering, Addy Osmani](https://addyosmani.com/blog/agent-harness-engineering/): short and practical, including the habit of turning every agent mistake into a permanent rule.

## 1 hour

- [Effective harnesses for long-running agents, Anthropic](https://www.anthropic.com/engineering/effective-harnesses-for-long-running-agents)
- [Harness design for long-running application development, Anthropic](https://www.anthropic.com/engineering/harness-design-long-running-apps): the planner, generator and evaluator setup behind the maker and checker prompts.
- [Harness engineering: leveraging Codex in an agent-first world, OpenAI](https://openai.com/index/harness-engineering/)
- [Harness engineering for coding agent users, Birgitta Böckeler (Thoughtworks), martinfowler.com](https://martinfowler.com/articles/harness-engineering.html)
- [Improving Deep Agents with harness engineering, LangChain](https://www.langchain.com/blog/improving-deep-agents-with-harness-engineering)

## Going deep

- [Course website](https://walkinglabs.github.io/learn-harness-engineering/): 14 lectures and hands-on projects, including loops and graphs.
- [Awesome Harness Engineering (ai-boost)](https://github.com/ai-boost/awesome-harness-engineering): curated papers, posts and implementations.
- [Agentic Harness Engineering, arXiv 2604.25850](https://arxiv.org/abs/2604.25850): automating harness improvement.
- [Harness Engineering: Anatomy, Architecture, and Evolution of Coding Agents, arXiv 2609.00006](https://arxiv.org/abs/2609.00006): source-code study of eleven coding agents.

## A note on evidence

The templates here are a starting point based on these public sources, not a guarantee of results. Measure it yourself: run the same task once with only a prompt and once with the harness, and compare how often it finishes correctly.
